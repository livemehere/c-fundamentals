# char

```c
char a[] = "hello";
char* b = "hello";

printf("%zu\n", sizeof(a)); // 6
printf("%zu\n", sizeof(b)); // 8
```

문자열을 선언할 때 배열 vs 포인터에 차이가있다.   

- 배열 : 실제 데이터를 포함한 메모리 공간을 가진다(stack, static 영역, global data 영역)
- char 포인터 : 주소만 저장하고, 데이터는 다른곳에 저장된다.(.rodata)

일반적인 배열의 크기는 컴파일 타임에 결정된다.
배열은 보통 수정 가능하고, 문자열 literal을 가리키는 포인터는 수정 불가능하다.


## 동적 사용

배열은 항상 고정된 크기라는 점을 명심해야한다.   
메모리로 어떻게 조작하든 값은 들어가고 정상적으로 출력되는것 처럼 보이지만 sizeof 는 고정된값으로 변하지않고, 할당받은 메모리 범위를 넘어 다른 메모리를 침범하면 문제가 된다.
이 현상이 Buffer overflow 이다. C는 배열 범위를 검사하지 않기 때문에, 범위를 벗어난 접근은 Undefined Behavior이다.

```c
char s1[] = "hello world";
printf("size : %lu\n", sizeof(s1)); // 12
memmove(s1+5, s1+6,6); // 이건 배열 크기가 줄어든 것이 아니다. (memmove는 데이터를 이동할 뿐이며, 배열의 capacity나 size를 관리하지 않는다.)
printf("res : %s\n", s1);
printf("size : %lu\n", sizeof(s1)); // 12
```

그래서 동적으로 사용하려면, `realloc` 을 미리하여 공간을 확보해서 사용한다.   
근데 보통 c 에서는 고정된 배열의 크기를 넉넉하게 잡아놓고 사용한다. 아니면 string 처럼 구조체를 만들거나

```c
char* s1 = malloc(6);
strcpy(s1, "Hello");
printf("size : %lu\n", strlen(s1)); // 5
char* temp = realloc(s1, 12);
if (temp){
    s1 = temp;
} else {
    free(s1);
}
printf("size : %lu\n", strlen(s1)); // 5
strcat(s1, " world");
printf("res : %s\n", s1);
printf("size : %lu\n", strlen(s1)); // 11
```
